## 🧩 Funcionalidades

- ✅ Navegação entre páginas sem recarregamento com **React Router**
- ✅ **Animações suaves** com Framer Motion
- ✅ **Responsivo** para todos os tamanhos de tela
- ✅ Estrutura 100% modular com **CSS Modules**
- ✅ Layout fixo com **altura 100vh** em todas as telas
- ✅ Ícones e estilo de código com foco em **programadores**
- ✅ Organização clara: **Home**, **Sobre Mim**, **Projetos**, **Contato**
- ✅ Estilização fiel ao design (Figma) com **imagem de fundo animada**
- ✅ Uso de variáveis de cor para facilitar manutenções futuras

## 📂 Estrutura do Projeto

```
.
├── src/ ------------------------------------------ # Código-fonte da aplicação
│
├── assets/ --------------------------------------- # 📁 Imagens, SVGs e outros arquivos estáticos
│
├── components/ ----------------------------------- # 📁 Componentes reutilizáveis
│   ├── AboutSections/ -------------------------- # 📁 Seções da página "Sobre"
│   │   ├── CareerBio/
│   │   ├── ContactInfo/
│   │   ├── PersonalInfo/
│   │   └── Tools/
│   ├── Footer/ --------------------------------- # 📁 Rodapé da aplicação
│   ├── Header/ --------------------------------- # 📁 Cabeçalho da aplicação
│   ├── HomeContent/ ---------------------------- # 📁 Componentes da página inicial
│   └── ProjectCard/ ---------------------------- # 📁 Cartão de projeto
│
├── pages/ ---------------------------------------- # 📁 Páginas principais da aplicação
│   ├── About/
│   ├── Contact/
│   ├── Home/
│   └── Projects/
│
├── routes/ --------------------------------------- # 📁 Arquivos de configuração de rotas
│
├── styles/ --------------------------------------- # 📁 Estilos globais e variáveis
│
└── App.tsx --------------------------------------- # 📄 Arquivo principal da aplicação
```
